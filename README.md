# Prodesk IT — Corporate Landing Page
### Sprint 1: The Corporate Brand

A fully responsive corporate landing page built for **Prodesk IT**, a digital marketing wing. Built with raw HTML, CSS (Flexbox & Grid), and vanilla JavaScript — no UI frameworks used.

## 🚀 Features

### Phase 1 — Base MVP ✅
- **Navbar** — Logo aligned left, navigation links (Home, About, Services, Contact) aligned right. Collapses to hamburger menu on mobile.
- **Hero Section** — High-conversion headline, sub-headline, and a "Get Started" CTA button.
- **Services Grid** — 3 service cards (SEO, Web Development, Marketing) built with CSS Grid.
- **Footer** — Copyright text and social media icons.
- **Fully Responsive** — Works on mobile and desktop viewports.

### Phase 2 — UI/UX Enhancements ✅
- **Dark/Light Mode Toggle** — Implemented via vanilla JavaScript toggling a CSS class on `<body>`.
- **Hover Micro-Interactions** — Color/scale shifts on CTA buttons, z-axis lift effects on service cards.
- **Sticky Navbar** — Navbar fixed to the top of the viewport during scroll.

| Technology | Usage |
